# Relay Roadmap

---

# v1 — Foundation

Goal:
Establish the core orchestration experience.

## Core Features

- Sequential orchestration
- Streaming responses
- Multi-agent workflows
- BYOK architecture
- Workspace UI
- Markdown rendering
- Provider support
- Model selection

## Focus Areas

Prioritize:
- orchestration reliability
- clean UX
- maintainable architecture
- operational simplicity

Avoid:
- premature complexity
- excessive infrastructure
- autonomous workflows

---

# v2 — Persistence & Collaboration

Goal:
Improve long-term usability and workflow continuity.

## Planned Features

- authentication
- persistent projects
- conversation history
- saved workflows
- collaborative workspaces
- encrypted provider storage

## Focus Areas

Prioritize:
- usability
- workflow continuity
- reliability
- secure storage

---

# v3 — Workflow Expansion

Goal:
Expand orchestration flexibility and integrations.

## Planned Features

- branching workflows
- conditional orchestration
- custom agents
- GitHub integration
- exportable artifacts
- tool calling
- web search integration

## Focus Areas

Prioritize:
- modularity
- extensibility
- orchestration transparency

Avoid:
- uncontrolled agent autonomy
- opaque workflows
- feature overload

---

# Long-Term Direction

Relay should evolve into:
- a structured AI collaboration platform
- a practical engineering workflow tool
- a reliable orchestration workspace

Relay should NOT become:
- an autonomous AGI simulator
- a chaotic multi-agent playground
- a hype-driven AI experiment
