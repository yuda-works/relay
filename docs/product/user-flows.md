# Relay User Flows

---

# Primary Workflow

```txt
User enters product idea
    ↓
User selects provider/model
    ↓
User starts orchestration
    ↓
Agents execute sequentially
    ↓
Outputs stream in real-time
    ↓
User reviews generated outputs
    ↓
User exports or copies results
```

---

# First-Time User Flow

```txt
User opens Relay
    ↓
User configures provider API key
    ↓
User selects model
    ↓
User enters product idea
    ↓
Orchestration begins
```

---

# Provider Configuration Flow

```txt
User opens provider settings
    ↓
User selects provider
    ↓
User enters API key
    ↓
Provider validation occurs
    ↓
Settings saved locally
```

---

# Orchestration Flow

```txt
User submits prompt
    ↓
Orchestrator initializes workflow
    ↓
Business Analyst executes
    ↓
System Analyst executes
    ↓
Product Manager executes
    ↓
UX Designer executes
    ↓
Software Architect executes
    ↓
Software Engineer executes
    ↓
QA Engineer executes
    ↓
Technical Writer executes
    ↓
Reviewer executes
    ↓
Final orchestration output generated
```

---

# Export Flow

```txt
User reviews outputs
    ↓
User exports markdown
    ↓
Download generated artifact
```

---

# UX Principles

User flows should always feel:
- predictable
- understandable
- structured
- calm
- responsive

Users should always understand:
- which agent is active
- orchestration progress
- output relationships
- workflow state

Avoid:
- hidden orchestration behavior
- unexplained automation
- confusing workflow transitions
